# ONG Transformando Vidas
Projeto acadêmico demonstrativo de HTML5 semântico, CSS responsivo e validação de formulários. Abra `index.html` no navegador. Os dados do formulário não são enviados. Imagens SVG ilustrativas.

Valide individualmente `index.html`, `projetos.html` e `cadastro.html` em https://validator.w3.org/nu/ usando entrada por texto ou upload.
